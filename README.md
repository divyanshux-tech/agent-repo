## 📖 Overview
**Plan Through Us** is an advanced AI-driven travel planning platform. Powered by a swarm of specialized AI agents (Nura), the platform converses with users in natural language (both text and voice, with multilingual support) to construct personalized, optimized travel itineraries, handle real-time bookings, and provide a post-booking companion for checklists, document vaults, and live flight tracking.

## ⚡ Key Features
- **🤖 Agentic AI Orchestration:** A central orchestrator delegates tasks to specialized sub-agents (Destination, Travel, Hotel, Activity, Expense, Optimizer, Itinerary).
- **🎙️ Multilingual Voice Interface:** Interact via voice. Built-in Bhashini provider for Indic languages (Hindi, etc.).
- **💬 Real-Time Streaming Chat:** Server-Sent Events (SSE) provide a fluid chat experience with interactive UI tool steps.
- **🧳 Post-Booking Companion:** 
  - Smart packing checklists generated by Gemini.
  - Secure Document Vault (via Cloudinary).
  - Live Flight Tracker (via OpenSky).
- **🧠 Advanced Memory & RAG:** Remembers user preferences across sessions and grounds destination suggestions using vector embeddings.

## 🏗️ Architecture Workflow

1. **User Input:** User speaks or types a request.
2. **NLU & Orchestration:** `NLUService` identifies intents (e.g., `START_PLANNING`, `GET_WEATHER`, `GET_PACKING_LIST`).
3. **Agent Delegation:** The `Orchestrator` delegates to:
    - **Destination Agent:** Recommends locations based on RAG knowledge base.
    - **Planner Agents:** (Travel, Hotel, Activity) fetch real-time candidates.
    - **Optimizer Agent:** Packs options into a cohesive, budget-friendly plan.
4. **Interactive UI:** Frontend listens via SSE and dynamically renders interactive cards (FlightCard, HotelCard).
5. **Booking:** Once confirmed, the system initializes the **Post-Booking Companion**.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- Python 3.10+
- Supabase project
- API Keys: Google Gemini, Cloudinary

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/divyanshux-tech/agent-repo.git
   cd agent-repo
   ```

2. **Backend Setup:**
   ```bash
   cd backend
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env
   # Add your API keys to .env
   uvicorn main:app --reload
   ```

3. **Frontend Setup:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

## 📂 Repository Structure
- `/backend`: FastAPI Python server, Agent swarm, PostgreSQL/Supabase models.
- `/frontend`: Vite+React app, Tailwind CSS, SSE hooks, modern dynamic UI components.
- `/scripts`: Utility scripts for seeding destinations, activities, and vector embeddings.
